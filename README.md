# Multi-Doc Router API

An API that takes a question (no document specified) and **automatically routes it** to the most relevant document out of 3 sample documents using vector similarity, retrieves relevant context from a vector store, and generates an answer using a local LLM — complete with an explanation of the routing decision.

## Stack
- **Framework**: FastAPI (Swagger docs at `/docs`)
- **Orchestration**: LangGraph (StateGraph with router and answer nodes, conditional edge for refusal)
- **Embedding Model**: `bge-m3` via Ollama (1024-dimension dense embeddings)
- **Vector Store**: ChromaDB (isolated collection per document)
- **LLM**: `llama3.2` via Ollama for grounded answer generation

---

## Architecture Flow

```
                           ┌───────────────────┐
      POST /ask-router ──▶ │    Router Node    │ ──▶ Embed question with BGE-M3
                           │    (LangGraph)    │     Compare with Doc summaries
                           └─────────┬─────────┘     Compute cosine similarity & score gap
                                     │
                        ┌────────────┴────────────┐
                        │                         │
             Confident? │                         │ Ambiguous / Low confidence?
             (gap >= 0.05 & sim >= 0.25)          │ (gap < 0.05 or sim < 0.25)
                        ▼                         ▼
             ┌─────────────────────┐    ┌───────────────────────────────────┐
             │     Answer Node     │    │          Refusal Output           │
             │     (LangGraph)     │    │  {"answer": null,                 │
             │                     │    │   "chosen_doc": null,             │
             │ 1. Query ChromaDB   │    │   "reason": "ambiguous — ..."}    │
             │    for chosen doc   │    └───────────────────────────────────┘
             │ 2. Prompt Llama 3.2 │
             │    with context     │
             └──────────┬──────────┘
                        │
                        ▼
             ┌──────────────────────────────────────────────┐
             │                Final Response                │
             │  {"answer": "...",                           │
             │   "chosen_doc": "Photosynthesis in Plants",  │
             │   "reason": "closest topic match: 0.45 ..."} │
             └──────────────────────────────────────────────┘
```

## Setup & Running

### 1. Prerequisites
- Python 3.10+
- [Ollama](https://ollama.com/) running locally with models pulled:
  ```bash
  ollama pull bge-m3
  ollama pull llama3.2
  ```

### 2. Install Python Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run FastAPI Application
```bash
uvicorn main:app --reload --port 8000
```
- API Endpoint: `http://localhost:8000/ask-router`
- Interactive Swagger UI: `http://localhost:8000/docs`
- Health check: `http://localhost:8000/health`

## Routing & Ambiguity Logic

1. The user's question is embedded into a 1024-dimensional vector using `bge-m3`.
2. Cosine similarity is computed between the question vector and each document's pre-computed summary vector.
3. Scores are sorted in descending order:
   - `best_score`: Top similarity score
   - `second_score`: Second highest similarity score
   - `gap = best_score - second_score`
4. **Refusal Condition**:
   - If `best_score < 0.25` (too far from any doc) OR `gap < 0.05` (too close to decide), the router flags the question as ambiguous and returns:
     ```json
     {
       "answer": null,
       "chosen_doc": null,
       "reason": "ambiguous — matches multiple docs (best: python_programming=0.46, next: photosynthesis=0.42, gap=0.04)"
     }
     ```
5. If confident, LangGraph transitions to the `answer` node, queries the ChromaDB collection for the selected document, and prompts `llama3.2` with the retrieved context.

## Example `curl` Requests & Responses

### 1. Photosynthesis Question (Routes to Biology Doc)
```bash
curl -X POST "http://localhost:8000/ask-router" \
  -H "Content-Type: application/json" \
  -d '{"question": "What is the Calvin cycle and where does it occur?"}'
```
**Response:**
```json
{
  "answer": "The Calvin cycle is a series of enzyme-catalyzed reactions that use the ATP and NADPH generated by the light reactions to fix carbon dioxide (CO2) from the atmosphere into organic molecules, such as glucose. It occurs in the stroma of the chloroplast.",
  "chosen_doc": "Photosynthesis in Plants",
  "reason": "closest topic match: 0.45 similarity vs 0.31 for next best (black_holes)"
}
```
